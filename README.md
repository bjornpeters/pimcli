# pimcli

Simple CLI for managing Priviliged Identity Management (PIM) in Microsoft Azure. Since it is a experimental project, it is not recommended for production use.

## Installation

In the PowerShell terminal, run the following command to import the module:

```powershell
./New-OfflineImport.ps1  
```

## Usage

From the PowerShell terminal, run the following command to start the CLI:

```powershell
Start-PimCli
```
